# Календарь звонков

Сервис записи на звонки фиксированной длительности по мотивам Cal.com. Гость выбирает свободный слот и занимает его; способ связи — вне зоны сервиса.

## Language

**Звонок (Call)**:
Абстрактная встреча фиксированной длительности 30 минут. Способ связи (телефон, видеозвонок) не определяется сервисом.
_Avoid_: встреча, консультация, сессия

**Запись (Booking)**:
Процесс и результат занятия слота гостем. Канонический термин и для действия, и для артефакта.
_Avoid_: бронирование, резервация, appointment

**Слот (Slot)**:
Конкретный 30-минутный интервал, который может быть занят одной записью (напр. «вт 15:00–15:30»). Генерируется из расписания организатора; окно доступности — отдельное понятие, если вводится.
_Avoid_: время, тайм-слот, окно (для конкретного интервала)

**Организатор (Host)**:
Владелец календаря, чьи слоты предлагает сервис. Логинится. На MVP — единственный организатор.
_Avoid_: администратор, владелец, юзер

**Гость (Invitee)**:
Записывающийся на звонок. Аноним, аккаунта не имеет; указывает имя и e-mail при записи.
_Avoid_: клиент, пользователь, посетитель

**Уведомление (Notification)**:
E-mail, отправляемый при создании записи. Информирует стороны, не является шлюзом подтверждения.
_Avoid_: подтверждение (для e-mail), письмо

**Подтверждение (Confirmation)**:
В копирайте UI «подтверждение на e-mail» означает уведомление, а не состояние записи. Запись создаётся мгновенно в состоянии confirmed; одобрения организатором нет.
_Avoid_: одобрение, аппрув, pending
